# Phase 1a device checklist (mobile)

Needs two accounts on a server with the phase 1a endpoints.

1. BOARD opens on FEED; pull to refresh; scroll loads more; empty and offline states show a retry button.
2. Run cards show initials, name, time, distance, moving time, pace, cells claimed, "took N from X"; no route line anywhere.
3. Kudos toggles at once and survives a refresh; comment count opens run detail.
4. Add a comment; delete your own; as run owner delete another's. Report a comment and a run card.
5. Open a public profile: stats, follow/unfollow, block (profile disappears from feed and search), report.
6. YOU: edit display name (profanity rejected with a sentence), run history, followers, following, find runners, blocked users with unblock.
7. RIVALS and battles summary load; "take it back" on the map draws the lost cells and moves the camera.
8. Inbox bell shows the unread count on the map; opening the inbox marks items read and the count drops.
9. All four themes: no unreadable text; font scale 200 percent keeps tap targets reachable (48 dp).
10. TalkBack reads the kudos, comment, follow and bell controls with sensible labels.
